## What this is

The marketing, content, and outreach skills I use to get things seen. No code copied here, only links to the originals plus notes on when each one is worth using.

## What's inside

| Tool | What it does | Link | License | My note |
|------|--------------|------|---------|---------|
| marketing-skills | Full marketing bundle: ads, SEO, email, CRO, and more | bundled with my agent environment | check upstream | The big one. Reach for it for any marketing question first. |
| linkedin-skills | LinkedIn posts, comments, profile toolkit | [sergebulaev/linkedin-skills](https://github.com/sergebulaev/linkedin-skills) | MIT | Drafts, audits, and publishing flow for LinkedIn. I use the manual tier. |
| humanizer | Removes AI tells from text | [blader/humanizer](https://github.com/blader/humanizer) | MIT | I run every public-facing word through this. No exceptions. |
| last30days | 30-day topic research across Reddit, X, YouTube, HN | [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill) | check upstream | For finding out what people actually say about a topic right now. |
| youtube-agent-skill | YouTube channel research | [Jakeschincariol/youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill) | MIT | Research channels and formats before making content. |

## How I use these

Content idea: last30days to see what people care about, youtube-agent-skill if it is video, marketing-skills for the strategy, humanizer on every word before it goes out. LinkedIn work goes through linkedin-skills with manual approval on every post.

## How to use this list

Pick the tool that matches your problem, follow its link, install it per its own README. Star the ones you keep coming back to.
